# Screenshot guide for CodeAlpha submission

Run the application locally and create a `screenshots` folder in the project root. Capture the real running website; do not use mockups as proof of functionality.

| Filename | Page / state | What should be visible |
|---|---|---|
| 01-homepage.png | `/` | Store header and several product cards |
| 02-product-details.png | `/product/<id>/` | Product name, description, price, stock, Add to cart |
| 03-shopping-cart.png | `/cart/` | Product row, quantity, subtotal, checkout button |
| 04-login.png | `/login/` | Login form |
| 05-checkout.png | `/checkout/` | Delivery fields and order total |
| 06-order-history.png | `/orders/` | A successfully placed order |
| 07-admin-products.png | `/admin/shop/product/` | Product list in Django Admin |

Recommended: use a desktop browser at a readable zoom level, hide personal information, and do not include passwords or private customer details in screenshots.
